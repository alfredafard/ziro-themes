# Themes directory

## Structure

- `starship/` — Official Starship presets (curated by ziro). Do NOT submit here.
- `<github-username>/` — Community contributions. Submit via `ziro theme submit`.

Themes in `starship/` are maintained by the [Starship project](https://starship.rs/presets/) (Matan Kushner and contributors). Ziro curates them for convenience — they are not ziro-created.
